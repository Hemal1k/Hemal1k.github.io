Code signing policy

For HeMiDock, HeMiUnlocker and HeMiPad.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only the installers and programs released on the GitHub pages of these projects (HeMiDock, HeMiUnlocker and HeMiPad). They are built by GitHub Actions from the public source code of each repository; nothing built elsewhere is signed.

Team roles

  • Committers and reviewers: Richard Hemala (Hemal1k)
  • Approvers: Richard Hemala (Hemal1k)

Every signing request is approved by hand. The accounts use multi-factor authentication on GitHub and SignPath.

Privacy policy

HeMiUnlocker and HeMiPad do not connect to the internet. HeMiDock connects only to:

  • GitHub – to look for a new version (can be switched off in Settings → About);
  • Open-Meteo – for the weather, only when the weather is switched on (the name of the chosen city is sent);
  • the European Central Bank – the exchange rates for currency conversions in the search (can be switched off in the search options);
  • a web page the user pins to the dock – for its icon;
  • an internet calendar – only the one the user adds.

No personal data and no usage data is collected or sent anywhere.
