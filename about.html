Privacy and security

How the HeMi apps work: what they install, what they send over the internet, where they keep your settings, and how you can check that a download is the real one.

The rules all the apps follow

Free and open source

Every line of code is public on GitHub under the MIT license. No paid versions, no locked features.

No ads, no tracking

No analytics, no telemetry, no accounts. Nothing about you or how you use the apps is collected or sent anywhere.

Only for your account

The installers put the apps into your own user folder – no administrator rights, no system services, nothing that runs for other users.

Clean to remove

Uninstall in Windows Settings → Apps. The uninstaller also removes the File Explorer items and the start-up entries the apps made.

What goes over the internet

HeMiUnlockerNothing. It never connects to the internet.
HeMiPadNothing. It never connects to the internet – even the spell check uses the dictionaries already in Windows.
HeMi DarkNothing – it is a set of skin files for VLC, not a program.
HeMiDock Only these, and only for the feature that needs them:
  • GitHub – once a day it asks whether a new version was released (on by default; Settings → About HeMiDock → Updates).
  • Open-Meteo – the weather, only when you switch it on: the city name you type to find it, then only its coordinates.
  • The European Central Bank – the exchange rates, only when you type a currency conversion into the search (at most twice a day).
  • A web page you pin to the dock – its icon, once, when you pin it.
  • An internet calendar – only the calendar address you add yourself.
All of it over HTTPS, without any identifier of you or your PC.

Where your settings are

Everything stays on your PC, in your user profile:

HeMiDock%AppData%\HeMiDock – settings, pinned apps, workspaces, backups of the settings and a log of errors (for you, it is not sent anywhere).
HeMiPad%AppData%\HeMiPad\settings.ini
HeMiUnlockerKeeps no settings; only the optional File Explorer item is written to HKCU\Software\Classes.
The programs%LocalAppData%\Programs\<app> when installed; the portable versions run from any folder.

Safe downloads

  • Built in the open. Every download is built by GitHub Actions from the public source of its version – you can see the build log of each release on the Actions page of the project.
  • Checksums. Each release has a SHA256SUMS.txt. To compare, open PowerShell in the download folder and run Get-FileHash HeMiDock-Setup.exe – the hash must be the same as in the file.
  • Updates only from the project. HeMiDock downloads its updates only from the Releases of its own GitHub project, over HTTPS, and installs them only after you agree.
  • Windows SmartScreen. New programs without a known signature can get the warning “Windows protected your PC” the first time. Until the apps are signed, choose More info → Run anyway – or check the checksum first.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • What is signed: only the installers and programs of HeMiDock, HeMiUnlocker and HeMiPad released on GitHub. They are built by GitHub Actions from the public source of each repository; nothing built elsewhere is signed.
  • Committers and reviewers: Richard Hemala (Hemal1k)
  • Approvers: Richard Hemala (Hemal1k)
  • Every signing request is approved by hand. The accounts use multi-factor authentication on GitHub and SignPath.
  • Privacy: these programs do not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating them – see What goes over the internet above.

Problems and questions

  • Bugs and ideas: the Issues page of the project (HeMiDock, HeMiUnlocker, HeMiPad, HeMi Dark).
  • A security problem: please report it privately – the Security tab of the project → Report a vulnerability – not as a public issue.
  • License: MIT – free to use, change and share. The apps come without warranty; they are in beta, so keep a backup of anything important as always.
