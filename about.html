Privacy and security

How the HeMi apps work: what they install, what they send over the internet, where they keep your settings, and how you can check that a download is the real one.

The rules all the apps follow

Free and open source

Every line of code is public on GitHub under the MIT license. No paid versions, no locked features.

No ads, no tracking

No analytics, no telemetry, no accounts. The apps connect only where a feature needs it (listed below for each app) – never to collect anything about you or how you use them.

What goes over the internet

HeMi LauncherOnly GitHub: it asks for the latest releases of the HeMi apps (after its start and then as often as you set – every 1 to 24 hours –, or when you click Refresh) and downloads the installers of the apps you install or update – over HTTPS, without any identifier of you or your PC.
HeMiPixThe photos never leave your PC. Only when you install Microsoft's free HEIF / HEVC extensions (asked first): winget and the Microsoft Store.
HeMiUnlockerNothing. It never connects to the internet.
HeMiPadNothing. It never connects to the internet – even the spell check uses the dictionaries already in Windows.
HeMiMizerGitHub at the start – whether a newer HeMiMizer is out (switch it off in Settings → Updates; with HeMi Launcher on the PC it does not ask). Otherwise only for what you chose:
  • the programs through winget – from their makers and the Microsoft Store (winget has its own telemetry, run by Microsoft);
  • HeMi Launcher, the other HeMi apps and ArtCraft from GitHub;
  • Microsoft – the Visual C++, DirectX and .NET runtimes, winget itself when it is missing, Windows Update and the Microsoft Store; for the tool “Download Windows” microsoft.com (including the session check its download page requires), for “Make a custom Windows ISO” msdl.microsoft.com;
  • the AMD drivers from amd.com;
  • a check whether the PC is online (msftconnecttest.com – only a connection, no data);
  • with “Encrypted DNS” switched on (off by default): all DNS queries of the PC go to Cloudflare (1.1.1.1) over HTTPS;
  • your network drives, when you add them.
Your backup stays in the folder you chose – nothing of it is sent anywhere.
HeMiTube On YouTube (and YouTube videos embedded in other websites), and only for the feature that needs it:
  • Return YouTube Dislike – the dislike count: the ID of the video you open (and, as with any request, your IP address). On by default; turn the module off if you don't want it.
  • SponsorBlock – skipping sponsors, only when you turn it on (the browser asks first): the first 4 characters of a SHA-256 hash of the video ID – shared by thousands of videos, so the server does not learn exactly which video you watch.
No analytics, no telemetry, no remote code; it never votes and sends nothing else.
HeMi DarkNothing – it is a set of skin files for VLC, not a program.
HeMiDock Only these, and only for the feature that needs them:
  • GitHub – once a day it asks whether a new version was released (on by default; Settings → General → Updates). With HeMi Launcher on the PC the launcher does that instead.
  • Open-Meteo – the weather, only when you switch it on: the city name you type to find it, then only its coordinates.
  • The European Central Bank – the exchange rates, only when you type a currency conversion into the search (at most twice a day).
  • A web page you pin to the dock – the page and its icon, once, when you pin it.
  • An internet calendar – only the calendar address you add yourself, every 15 minutes.
  • Microsoft – the .NET and Windows App runtimes, only when they are missing (the installer, or HeMiDock after asking you).
Without any identifier of you or your PC, and over HTTPS – except a pinned web page or an internet calendar whose address you give as http://.

Where your settings are

Everything stays on your PC, in your user profile. HeMiPix, HeMiPad, HeMiUnlocker, HeMiMizer and HeMi Launcher write a log only when you turn on Logging in their settings: log.txt in the same folder, at most 1 MB, with your user folder written as %USERPROFILE%.

HeMiDock%AppData%\HeMi\HeMiDock – settings, pinned apps, workspaces, backups of the settings; a log only while you switch on debug mode in its settings (it stays on your PC, nothing is sent).
HeMiPix%AppData%\HeMi\HeMiPix\settings.ini; the photos it makes go where you choose (next to the originals by default).
HeMiPad%AppData%\HeMi\HeMiPad\settings.ini
HeMiMizerEverything in the folder HeMiMizer data next to HeMiMizer.exe: the backup (settings, installers, your folders). Its own settings (and its log) are in %AppData%\HeMi\HeMiMizer. Done at the end removes HeMiMizer and everything it put on the new PC – nothing of it stays.
HeMi Launcher%AppData%\HeMi\HeMiLauncher\settings.ini; for the other HeMi apps it notes where it is (HKCU\Software\HeMi\HeMiLauncher) and which updates it found (%LocalAppData%\HeMi\HeMiLauncher).
HeMiTubeIn your browser's own storage (synced with your browser account if you use sync); export and import as JSON in its settings.
HeMi DarkInstalled by HeMi Launcher: %AppData%\vlc\skins\HeMiDark; the skin chosen is written to the settings of VLC (%AppData%\vlc\vlcrc – a copy as it was before is kept next to it).
HeMiUnlockerIts look and language in %AppData%\HeMi\HeMiUnlocker\appearance.ini; the optional File Explorer submenu in HKCU\Software\Classes (and, for the notifications of “Unlock”, its name and icon); after Take ownership the previous owners and permissions in %ProgramData%\HeMi\HeMiUnlocker\ownership-undo, so that Undo can put them back.
The programsThe installer asks: just for you (%LocalAppData%\Programs\HeMi\<app>, no administrator rights) or for all users (Program Files\HeMi\<app>) – one HeMi folder, like the settings, x64 or ARM64. Uninstalling asks whether to delete the settings or keep them. The portable versions run from any folder.

Safe downloads

  • Built in the open. Every download is built by GitHub Actions from the public source of its version – you can see the build log of each release on the Actions page of the project.
  • Checksums. Each release has a SHA256SUMS.txt. To compare, open PowerShell in the download folder and run Get-FileHash HeMiDock-Setup.exe – the hash must be the same as in the file.
  • Updates only from the projects. HeMi Launcher, HeMiDock and HeMiMizer download updates only from the Releases of the HeMi projects on GitHub, over HTTPS, check every download against SHA256SUMS.txt first, and install them only after you agree (or after you switch on automatic installing in HeMi Launcher or HeMiDock).
  • Windows SmartScreen. The apps are not code-signed (a certificate costs hundreds of euros a year), so Windows can show “Windows protected your PC” the first time. Choose More info → Run anyway – or check the checksum first.

This website

It is hosted by GitHub Pages – like any web host, GitHub sees your IP address. To show the latest version numbers, your browser asks the GitHub API (api.github.com) for each app shown on the page at most once an hour – GitHub gets the same as from any visit: your IP address, your browser and that the request comes from this site. No cookies, no analytics; your browser keeps only the theme you chose and the version numbers (in its local storage). On a network shared by many people, GitHub can limit these requests – then the version numbers are simply not shown.

Problems and questions

  • Bugs and ideas: the Issues page of the project (HeMi Launcher, HeMiDock, HeMiPix, HeMiUnlocker, HeMiPad, HeMi Dark, HeMiMizer, HeMiTube).
  • A security problem: please report it privately – the Security tab of the project → Report a vulnerability – not as a public issue.
