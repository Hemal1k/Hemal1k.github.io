# hemal1k.github.io

The web of the HeMi apps for Windows: https://hemal1k.github.io – plain HTML and CSS, served by GitHub Pages.

| File | Page |
|---|---|
| `index.html` | All projects |
| `hemidock.html`, `hemiunlocker.html`, `hemipad.html`, `hemidark.html` | One page per project; the download buttons point to `releases/latest/download/<file>` of its repository |
| `about.html` | Privacy and security: the rules of the apps, what goes online, where the settings are, safe downloads, the code signing policy (SignPath) |
| `code-signing.html` | Redirects to `about.html#code-signing` (the address given to SignPath) |
| `assets/style.css` | The look (light / dark by the system) |
| `assets/*.png` | Icons, screenshots (`shot-*`) and the link previews (`og-*`, 1280 × 640, also the social previews of the repositories) |
