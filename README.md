# hemal1k.github.io

The website of the HeMi apps for Windows: https://hemal1k.github.io – plain HTML, CSS and a little JavaScript, served by GitHub Pages. English only (the apps themselves speak English and Czech).

| File | Page |
|---|---|
| `index.html` | All projects and the FAQ |
| `hemilauncher.html`, `hemidock.html`, `hemipix.html`, `hemiunlocker.html`, `hemipad.html`, `hemimizer.html`, `hemitube.html`, `hemidark.html` | One page per project; the download buttons point to `releases/latest/download/<file>` of its repository |
| `about.html` | Privacy and security: the rules of the apps, what goes online, where the settings are, safe downloads, this website |
| `code-signing.html` | An old address: redirects to `about.html` |
| `assets/style.css` | The look (Automatic / Light / Dark) |
| `assets/sketches.css` | The drawn previews of the apps on their pages |
| `assets/site.js` | The theme switch, the small animations of the previews and the version badges (from the GitHub API, cached for an hour in the browser) |
| `assets/*.png`, `assets/favicon.svg` | Icons, the HeMiTube screenshots (`hemitube-popup-*`) and the link previews (`og-*`, 1280 × 640, also the social previews of the repositories) |
